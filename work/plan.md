# 番组发现 / 追番站 —— 实现计划

## 目标与边界

- 纯前端静态站：HTML + CSS + 原生 JS，无后端、无登录、无构建步骤。
- 只做**信息展示与个人追番管理**：不提供在线播放、不爬取、不嵌入任何未授权视频源，
  详情页只给出「去正版平台观看」的文字指引（不跳转盗版站）。
- 封面不引用外部图片（离线也能显示）：用 CSS 渐变 + 标题 + 表情符号程序化生成占位封面。
- 响应式，手机可读；深色二次元风格，用渐变与细描边做质感，动画克制（并尊重
  `prefers-reduced-motion`，不做闪烁效果）。

## 数据设计

- 权威数据文件：`data/anime.json`（12 部示例番剧）。
- 因为 `file://` 直接打开时 `fetch()` 会被浏览器 CORS 拦截，另提供同内容的 JS 兜底
  `assets/js/data.js`：先尝试 `fetch` JSON，失败则用内置数组，保证双击 HTML 也能正常工作。
- 每部番剧字段：id / 标题（中/日/英）/ 年份 / 制作公司 / 状态 / 示例评分 / 时长 /
  分类（热血·日常·奇幻·治愈）/ 标签 / 集数 / 简介 / 配色 / 图标。
- 集数列表为**占位数据**，由 JS 按集数生成「第 N 集 + 占位简介」，不编造真实剧集信息。

## 本地存储（localStorage）

- 单一键：`anime-tracker:v1`
- 结构：
  ```
  {
    "favorites": { "<animeId>": { "addedAt": 1690000000000 } },
    "progress":  { "<animeId>": { "watched": [1,2,3], "updatedAt": 1690000000000 } },
    "recent":    [ { "id": "<animeId>", "at": 1690000000000 } ]
  }
  ```
- 收藏、取消收藏、按集标记已看、清空进度、清空全部，全部即时写入本地存储并在页面间共享。

## 文件结构（成品目录 outputs/anime-discovery）

```
anime-discovery/
├── index.html            首页：搜索 + 分类筛选 + 海报墙
├── detail.html           番剧详情：封面 / 简介 / 标签 / 集数列表 / 追番与进度
├── mylist.html           我的追番：收藏列表 + 观看进度 + 继续观看 + 最近浏览
├── about.html            关于页：只做信息展示的声明 + 正版平台指引
├── data/anime.json       12 部示例番剧数据（JSON）
├── assets/css/style.css  深色主题、响应式布局、组件样式
└── assets/js/
    ├── data.js           数据加载（fetch JSON + 内置兜底）、集数占位生成
    ├── store.js          localStorage 封装
    ├── ui.js             封面生成、卡片渲染、导航高亮、通用小工具
    ├── home.js           首页逻辑：搜索 / 筛选 / 排序 / 渲染
    ├── detail.js         详情页逻辑：渲染 + 集数勾选 + 追番按钮
    └── mylist.js         我的追番逻辑：收藏 / 进度 / 清空
└── README.md             使用说明 + 文件清单
```

## 实施步骤

1. 写数据文件 `data/anime.json`。
2. 写 `data.js`（加载 + 兜底 + 集数生成）与 `store.js`（localStorage）。
3. 写 `ui.js` + `style.css`：设计系统（配色变量、卡片、按钮、chip、进度条、海报墙网格）。
4. 写四个页面与其脚本，页面间用 `?id=` 传参。
5. 自检：JS 语法检查、JSON 校验、本地起静态服务器抓取页面与资源确认 200。
6. 写 README（打开方式 + 全部文件清单 + 免责声明）。
