## 逐项验证

### 1) 热门点击不离开本站 ✅

- 首页「本季 / 热门」23 张卡的链接全部指向 `detail.html?id=...`；
- 自动化检查 `#trendingStrip a` 中 host 不属于本站的链接数：**0**；
- 首页海报墙与热门条点击均进入站内详情页；外链只出现在详情页按钮区（MAL / Bangumi / AniList）。

### 2) 中文搜索可用 ✅

搜索字段覆盖：中文名、日文原名、罗马字、英文名、制作公司（中 / 英）、类型标签、分类、简介、年份。

### 3) 无 PV 的详情没有假播放器 ✅

主库 19 部没有官方 trailer。抽查 `detail.html?id=naruto-shippuuden`：

- `.pv-card` 不存在，「播放 PV」按钮数 **0**，页面 `iframe` 数 **0**；
- 对照 `detail.html?id=frieren`（有 trailer）：点击前 `iframe` 数 **0**，
  点「播放 PV」后才插入一个 `youtube-nocookie.com/embed/...` iframe（`mute=1` 默认静音），
  实测嵌入的是官方频道 TOHO animation 的预告片；
- 首页 / 我的追番 / 筛选结果等列表页 `iframe` 数均为 **0**，无任何视频预加载或自动播放。

### 4) 导入导出 / 分享码往返不丢收藏 ✅

实测步骤（我的追番页）：

1. 初始：2 部收藏（孤独摇滚! 4/12 集、葬送的芙莉莲 2/28 集），统计「在看 2」「有进度 2」「累计看过 6 集」；
2. 点「复制分享码」→ 生成 150 字符、以 `AD1.` 开头的分享码，页内提示复制成功；
3. 点「清空全部数据」并在确认框确认 → 统计全部归零，收藏列表为空；
4. 粘贴分享码 → 点「从分享码导入」→ 提示「共解析 2 条，新增收藏 2 条、进度 2 条」；
5. 复核：收藏 2、「在看 2」、「累计看过 6 集」、继续看 2 条 —— **与第 1 步完全一致**；
6. 导入是合并策略（取并集），重复导入不产生重复条目，也不会清空已有记录。

「导出记录 JSON」：点击后页内提示「已导出 2 条收藏记录。」，Blob + 下载锚点代码路径执行成功。
**已知限制**：Codex 内置浏览器不派发 Playwright `download` 事件，因此未自动验证文件落到磁盘，
建议在本机 Chrome / Edge 手动点一次确认（文件名 `anime-tracker-backup.json`）。

### 5) 封面裂图有占位 ✅

用临时 QA 页面（验证后已删除）覆盖两条路径：

- 图片 URL 不可达（模拟离线 / 图裂）：`<img>` 节点被移除、`cover-broken` 类生效，
  渐变 + 表情 + 标题的文字占位封面正常显示；
- 数据源没有返回封面 URL：直接渲染文字占位，同样不出现裂图。

线上实测 539 部封面 URL 全部为 `https://`，首屏懒加载生效，未观察到加载失败。

### 6) 未把大 dataset 或视频提交进仓库 ✅

提交前扫描（含待提交文件）：

- 仓库内图片 / 视频文件：**0 个**（jpg / png / webp / gif / mp4 / mkv / m3u8 全部为空）；
- 大于 1 MB 的文件：只有站点自身数据 `anime.json`、`anime.js`（各约 1.2 MB），不是原始数据集；
- `.gitignore` 已忽略 `work/api-cache/`（API 响应缓存）、`work/datasets/`（用户原始数据集）、
  `node_modules/`、`.env`、`*.pem`、`*.key` 等；
- 密钥特征扫描（`ghp_`、`github_pat_`、私钥头、password= 等）：未发现；
- 字段检查：539 条记录里不存在 magnet / torrent / 网盘 / 播放直链等任何字段。

本次运行环境中没有 `work/datasets/` 目录，A2（合并用户数据集）按设计跳过；
该目录已加入 `.gitignore`，以后放入原始数据集也不会被提交。

## 阶段自测记录

### A. 数据

- 重写 `work/fetch-anime-data.mjs`：AniList 批量分页（`POPULARITY_DESC`，TV / Movie / ONA，≥2005）
  + Bangumi（`api.bgm.tv/v0/search/subjects`，带文档要求的 User-Agent，间隔 ≥1.1 秒）补中文名与中文简介；
- 请求层：节流 ≥1.1s、单次 20s 超时、429 / 403 / 5xx 按 `Retry-After` 或指数退避重试（最多 4 次）、
  失败结果缓存 10 分钟、成功结果缓存 14 天；
- 健壮性：条数 < 300 判定抓取不完整，保留旧 JSON 不覆盖（小样本试跑时实测触发过该保护）；
  热门列表 < 10 条同样保留旧文件；
- 运行实况：AniList 共 12 页批量请求；Bangumi 539 次查询命中 476 条，期间 1 次 `fetch failed` 自动重试成功；
  首次完整抓取约 9 分钟，重跑全命中缓存只需数秒；
- 数据源优先级：AniList（主）→ Bangumi（中文）→ Jikan（可选回退；本次运行时 Jikan 持续 504，故未使用，报告如实记录）。

### B. 导航与 PV

- 首页 / 热门 / 相关推荐 / 时间轴中库内作品，点击一律进入站内详情；
- 外链只在详情页按钮区；
- PV 仅在详情页、仅有官方 trailer 时出现，点击后才创建 iframe，默认静音；
- 列表页与详情页初次加载 `iframe` 数均为 0（已实测）。

### C. 浏览

- 全站优先中文名；无中文名时显示日文原名，并在详情页显示「暂无中文名，显示原名」徽章；
- 详情页：大封面、中文速览（早期收录的 38 部保留本站编辑速览）、中文简介 + 英文简介（默认收起可展开）、
  标签、分数与收藏数、制作公司、集数进度、追番状态、数据来源徽章；
- 同系列时间轴：标注前作 / 续作 / 剧场版；库内作品可点进站内详情（带「✓ 站内已有」），
  库外作品只显示名称 + AniList 外链；
- URL 可分享：`?q= &genre= &year= &season= &studio= &format= &sort=`，浏览器前进 / 后退可还原筛选；
- 年份轴：2005–2026 共 23 个年份按钮（含「全部年份」），横向可滑动；
- 季度表：按选中年份（默认当前年）展示冬 / 春 / 夏 / 秋作品数，点击按该季度筛选；
- 制作公司：下拉列出 70 家（作品数 ≥2），选中即筛选（如 Kyoto Animation → 23 部）；
- 随机一部：按钮 + 快捷键 `R`。

### D. 追番与发现

- 四种状态：想看 / 在看 / 看完 / 弃番（详情页与卡片都能切换；未手动设置时按进度推导）；
- 我的追番统计：收藏 / 想看 / 在看 / 看完 / 弃番 / 累计看过集数，实测与预期一致；
- 「继续看」只列「在看」且有进度的作品，按最近观看时间倒序；
- 导出 JSON、导入 JSON、复制分享码、从分享码导入、清空（confirm 确认）均可用，往返测试见上；
- 「猜你也想看」按收藏作品的分类 / 类型标签 / 制作公司加权，纯前端计算，实测给出 6 部。

### E. 体验

- 封面 `loading="lazy"`，加载失败自动文字占位；
- 列表使用骨架屏占位（CSS 静态色块，不闪烁）；
- 筛选条件写入 URL + localStorage，从详情页返回不丢筛选；
- 键盘：`/` 聚焦搜索框（实测 activeElement 变为 `searchInput`）；`R` 随机一部；
  在输入框内输入 `r` 不触发随机（实测未跳转）；
- 390px 宽度实测：首页与详情页均无横向溢出（`scrollWidth == viewport`），年份轴与热门条横滑正常；
- 深色主题保持，动效克制，并遵循 `prefers-reduced-motion`。

## 已知限制

1. **中文名覆盖 87.8%**：剩余 66 部多为续作分季 / 剧场版分篇，Bangumi 未匹配到，
   页面显示日文原名或英文名，**不做机器翻译**。想提高覆盖率可在脚本里为这些条目补人工 `malId`。
2. **导出文件未做磁盘级验证**：内置浏览器不派发下载事件（见上）。
3. **总集数未知**的连载作品（如 ONE PIECE）按 24 集占位记录进度，页面已标注。
4. **Jikan 未参与本次数据**：运行时持续 504，脚本保留其逻辑但本次未启用。
5. **集数列表为占位条目**：只用于记录「看到第几集」，不代表真实剧集标题，站内已注明。
