About

关于本站

本站只做信息展示。 页面上的番剧名称、简介、分数、集数等资料来自公开 API（Jikan / MyAnimeList 与 AniList）， 封面图通过 API 返回的图片 URL 直接引用。本站不提供、不存储、不托管、不嵌入任何视频内容， 也不链接任何未授权片源。想观看正片，请前往持牌的正版平台。

这个站点做什么

  • 收录 38 部常见动漫作品，覆盖热血 / 日常 / 奇幻 / 治愈 / 科幻 / 悬疑，用真实封面海报墙展示。
  • 支持按标题（中文名 / 罗马字 / 日文名 / 英文名）、标签与简介关键词搜索，按分数、年份、集数排序。
  • 「本季 / 热门」区块展示当前热播连载作品，数据同样来自公开 API。
  • 可以收藏番剧、按集标记观看进度，并用「在看 / 看完 / 计划看」管理自己的追番状态。
  • 详情页可跳转到 MyAnimeList 或 AniList 的作品页，方便查看完整资料。

这个站点不做什么

  • ❌ 不提供在线播放、不提供播放器、不提供任何视频文件或 m3u8 / mp4 直链。
  • ❌ 不爬取、不转载、不嵌入盗版或未授权的视频源、字幕或资源。
  • ❌ 不提供网盘链接、磁力链、下载地址等任何侵权入口。
  • ❌ 不下载、不缓存、不重新分发任何封面图片；封面始终由原站 CDN 直接提供。
  • ❌ 不做用户账号、不做服务端存储，不收集你的个人信息。

数据与隐私

  • 番剧资料存放在项目内的 data/anime.json（热门列表在 data/trending.json），由 work/fetch-anime-data.mjs 抓取生成。
  • 收藏、进度与追番状态写在你浏览器的 localStorage（键名 anime-tracker:v1）， 清除浏览器数据即会清空，本站无法读取也无法恢复。
  • 页面不加载任何第三方脚本、统计或广告；只有封面图片来自外部 CDN。

数据来源与署名

  • Jikan API（首选） 社区维护的 MyAnimeList 公开 API（api.jikan.moe/v4），提供名称、简介、分数、集数、放送信息等。
  • AniList GraphQL API（回退） 当 Jikan 不可用时，脚本改用 AniList 获取同一批资料（graphql.anilist.co）； 这类条目在详情页的「作品信息 → 数据源」里标注为 AniList。
  • 封面图片 图片 URL 由上述 API 返回，实际文件托管在各自的 CDN 上，版权归原权利人所有； 本站只做引用，不下载、不转存、不裁剪、不加水印。
  • 中文名与中文速览 中文标题由本站整理；最早收录的 12 部附有本站编辑整理的中文速览，页面上已标注 「非官方简介」，其余全部以 API 原文为准，未做改写。

如果某个作品在 API 中没有匹配结果，脚本会保留占位条目并留空简介，不会编造内容。 本站与 MyAnimeList、AniList 均无隶属或合作关系。

去哪里看正片

以下是常见的正版观看渠道（仅作示例，请以各平台实际版权区域为准）：

  • 哔哩哔哩 / Bilibili 国内常见的动画正版播放平台，按地区上线情况购买会员即可观看。
  • Crunchyroll 覆盖北美、欧洲等地区，提供当季新番同步更新。
  • Netflix 部分番剧为全球或分区独占，附带多语言字幕。
  • 巴哈姆特动画疯 台湾地区的正版动画平台，需要登录并遵守其使用条款。

本站不会自动跳转到上述站点，请自行搜索并遵守各平台的服务条款与所在地法律。
