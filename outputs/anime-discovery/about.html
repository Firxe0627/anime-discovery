About

关于本站

本站只做信息展示。 页面上的番剧名称、简介、分数、集数等资料来自公开 API（主资料 AniList， 中文名与中文简介来自 Bangumi），封面通过 API 返回的图片 URL 直接引用， PV 使用 AniList 标注的官方 YouTube 视频嵌入。 本站不提供、不存储、不托管、不嵌入任何正片内容，不含磁力 / 网盘 / 直链入口， 也不下载或转存任何图片、视频文件。想看正片请前往正版平台。

这个站点做什么

  • 收录 539 部精选番剧（TV 481 / 剧场版 38 / 网络动画 20，2005 年至今）， 海报墙使用真实封面，按热度排序挑选，不做“把几万条离线库整包塞进前端”的事。
  • 中文名与中文简介来自 Bangumi；没有中文资料时显示日文原名或英文简介，不做机器翻译、不编造。
  • 支持中文 / 日文 / 英文 / 罗马字 / 制作公司关键词搜索，分类、年份轴、季度表、制作公司、类型（TV / 剧场版 / ONA）多维筛选。
  • 筛选条件写进网址（?q= &genre= &year= &season= &studio= &sort=），可以直接分享给朋友。
  • 详情页有中文速览、完整简介（默认收起）、标签、分数、制作公司、集数进度、追番状态、数据来源徽章与同系列时间轴。
  • 「本季 / 热门」区块展示近期热度最高的连载作品，点击同样进入站内详情页。
  • 我的追番支持想看 / 在看 / 看完 / 弃番、按集进度、继续看排序、猜你也想看、导出 / 导入 JSON 与分享码。

这个站点不做什么

  • ❌ 不提供在线播放正片、不提供播放器、不提供任何视频文件或 m3u8 / mp4 直链。
  • ❌ 不含磁力链、网盘链接、下载地址等任何侵权入口。
  • ❌ 不下载、不缓存、不重新分发封面图片；封面始终由原站 CDN 直接提供。
  • ❌ 不转存、不镜像 PV；PV 只在详情页由用户点击后嵌入官方 YouTube 播放器。
  • ❌ 不做账号系统、不做服务端存储、不收集个人信息，没有任何统计脚本或广告。

数据来源与署名

  • AniList GraphQL（主资料源） 提供名称（原名 / 罗马字 / 英文）、封面 URL、简介、分数与收藏数、集数、年份、季节、 放送状态、类型标签、制作公司、同系列 relations，以及官方 PV 的 YouTube 视频 id。
  • Bangumi（api.bgm.tv，中文源） 提供中文名与中文简介。抓取时带 Bangumi 要求的 User-Agent，请求间隔 ≥1 秒； 匹配不上就留空，前端自动显示原名或英文简介，绝不机器翻译。
  • Jikan（可选回退） 抓取脚本保留了 Jikan（MyAnimeList 公开 API）作为补充来源；本次运行时 Jikan 持续返回 504， 因此资料全部来自 AniList，抓取报告里如实记录。
  • 封面图片 图片 URL 由 AniList 返回，文件托管在其 CDN 上，版权归原权利人所有； 本站只做引用，不下载、不转存、不裁剪、不加水印。图片加载失败或离线时显示文字占位封面。

本次数据规模：539 部中 473 部有中文名、471 部有中文简介、520 部有官方 PV、439 部有同系列关系。 如果某个作品在数据源里匹配不到，脚本会跳过而不编造内容。

关于 PV（宣传影像）

  • 只有 AniList 明确标注为官方 YouTube trailer 的作品，详情页才会出现「PV」区块。
  • 默认不加载任何播放器：先显示「播放 PV」按钮，点击后才插入 YouTube 嵌入播放器，并默认静音，可在播放器里开声。
  • 列表页、首页、我的追番页都不会加载任何视频，也不做自动播放。
  • 没有官方 PV 的作品不会显示播放器，也不会随便找一个视频填上。

数据与隐私

  • 番剧资料存放在 data/anime.json（热门列表在 data/trending.json）， 由 work/fetch-anime-data.mjs 生成。
  • 收藏、进度与状态写在浏览器的 localStorage（键名 anime-tracker:v1）， 清除浏览器数据即会清空，本站无法读取也无法恢复；导出与分享码都在本地完成。
  • 本站没有使用任何第三方离线番剧数据库；work/datasets/ 目录（如果你放入原始数据集） 已被 .gitignore 忽略，不会提交进仓库。

去哪里看正片

以下是常见的正版观看渠道（仅作示例，请以各平台实际版权区域为准）：

  • 哔哩哔哩 / Bilibili国内常见的动画正版播放平台，按地区上线情况购买会员即可观看。
  • Crunchyroll覆盖北美、欧洲等地区，提供当季新番同步更新。
  • Netflix部分番剧为全球或分区独占，附带多语言字幕。
  • 巴哈姆特动画疯台湾地区的正版动画平台，需要登录并遵守其使用条款。

本站不会自动跳转到上述站点，请自行搜索并遵守各平台的服务条款与所在地法律。
